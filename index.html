Everything you reach for, one keypress away

Every action goes through a safety check first, and the dashboard refreshes after each change so what you see is what Git has.

🚀 Quick Commit & Push

Stage everything, commit and push in one step. It is the default selection when the dashboard opens.

📦 Package scripts

Lists your package.json scripts (npm, pnpm, yarn or bun) and runs the one you pick in a new terminal window.

🌐 Publish to GitHub

Create a public or private repo and push, in one flow. It installs and signs in the GitHub CLI for you if needed.

🌿 Branches & merges

Create, switch and delete branches with guards, start merges, see conflicts and abort cleanly.

🗃️ Stash & restore

Stash everything including untracked files, restore later, or stash and pull when a pull would collide.

🔍 Diff viewer

Read staged and unstaged diffs with colored +/- lines and scrolling, before you commit.

↩️ History with undo

Every action is recorded, and the safely reversible ones can be undone from the history screen.

📄 New file / folder

Create files and folders from inside the app, with a built-in editor for text and markdown.

🖱️ Right-click menu

Optional "Open Git Helper here" entry in Windows Explorer, for any folder.

Install in a minute

Windows. Git must be installed and on your PATH.

Download git-helper-v5.2.1.exe from the button above and put it in a folder you keep tools in.
Run it from any repository folder. 
git-helper-v5.2.1.exe
Optional: rename it to gitt.exe and add that folder to your PATH so gitt works in PowerShell, cmd and Git Bash. 
gitt            # open the dashboard
gitt -n         # list package.json scripts in the terminal
gitt --version

Built to not hurt you

The UI never talks to Git directly. Every destructive action passes a validation guard first, and the layers are strict.

Guards before actions

Deleting a branch, discarding changes or pushing is validated before it runs, with explicit confirmations.

Pushes just work

A missing upstream is set automatically on the first push instead of surfacing a raw Git error.

Older Git supported

Falls back from git switch to git checkout and from git restore to git reset.
