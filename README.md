# Git Helper showcase

Static site for Git Helper: `index.html` plus the Windows build in `downloads/`.

- **Deploy:** push to GitHub, then Settings → Pages → deploy from branch `main`, folder `/ (root)`.
- **Update:** copy the new `git-helper.exe` into `downloads/` as `git-helper-vX.Y.Z.exe` and replace the version in `index.html`.
- **Preview:** open `index.html` in a browser.
